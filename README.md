# TeleLogger 
**Бот для сохранения всех ваших сообщений из личных чатов.**

## Содержание
 - [Функционал бота](#bot_function)
   * Описание основных функций бота.
    
 - [Установка бота](#bot_installation)
   * Полное описание установки бота.


## <a id="bot_function"> Функционал бота </a>
 1. Сохранять сообщения
    - Текстовые сообщения
    - Фото сообщения
    - Видео сообщения
    - Аудио сообщения
    - Документы 
    - Голосовые
    - Кружки

 2. Поиск измененных сообщений
    - Отправляет измененное содержание, отвечая на оригинальное сообщение, если оно сохранено.

 3. Поиск удаленных сообщений
    - Отправляет уведомление об удалении, отвечая на оригинальное сообщение, если оно сохранено.

## <a id="bot_commands"> Команды бота </a>
 1. /start
    - При первом запуске бота выдает права администратора.
    - Далее выступает проверкой запущен ли бот или нет.

 2. /stats
    - Получение статистики чатов и сообщений из БД.

## <a id="bot_installation"> Установка бота </a>
 1. Загрузите и распакуйте архив с ботом

 2. Откройте терминал в корне распакованной папки
 
 3. Создайте виртуальное окружение:
    * Для Windows
    ```
    python -m venv venv
    ```
    * Для Linux/MacOS
    ```
    python3 -m venv venv
    ```

 4. Активируйте виртуальные окружение
 ```
 . venv/bin/activate
 ```
 
 5. Установите все нужные библиотеки из requirements.txt
    * Для Windows
    ```
    pip install -r requirements.txt
    ```
    * Для Linux/MacOS
    ```
    pip3 install -r requirements.txt
    ```
 
 6. Теперь вам нужно создать файл `.env`
 ```
 API = 'API_KEY' # API ключ телеграм бота.
 database_name = 'data.db' # Имя БД с ID сообщений.
 admin_id='' # Ничего указывать не надо !
 ```

 7. В виртуальном окружении запустите вашего бота
    * Для Windows
    ```
    python bot.py
    ```
    * Для Linux/MacOs
    ```
    python3 bot.py
    ```
